### Available fields

**For `type: "video"`** (also applies to `shortVideo` and `stream` items):

| Field | Type | Notes |
|-------|------|-------|
| `author` | string | Channel name |
| `authorId` | string | Channel ID |
| `authorUrl` | string | |
| `authorVerified` | boolean | |
| `published` | number | Unix timestamp |
| `publishedText` | string | e.g. "2 days ago" |
| `title` | string | |
| `type` | string | One of: `"video"`, `"shortVideo"`, `"stream"` |
| `videoId` | string | |
| `viewCount` | number | |
| `viewCountText` | string | |
| `lengthSeconds` | number | Duration in seconds |
| `premiereTimestamp` | number | |
| `isUpcoming` | boolean | |
| `premium` | boolean | |

**For `type: "channel"`:**

| Field | Type |
|-------|------|
| `author` | string |
| `authorId` | string |
| `authorUrl` | string |
| `authorVerified` | boolean |
| `autoGenerated` | boolean |
| `channelHandle` | string |
| `description` | string |
| `subCount` | number |

Operators supported: `equals`, `in`, `like`, `gt`, `lt`, `regex`.
